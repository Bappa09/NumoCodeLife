📲 How to Add to Google Calendar

  1. Click "Add to Google Calendar" on any classmate card below.
  2. Sign into Google → Click "Save" — it auto-sets as a yearly recurring event!
  3. Enable Notifications (1 day before) in Google Calendar settings.
  4. You'll get email + phone push reminders automatically every year. ✅

🌐 Embed This Page on Free Websites

  1. Save this HTML file and host it FREE on GitHub Pages, Netlify, or Tiiny.host.
  2. For GitHub Pages: Push file to a repo → Settings → Pages → Enable. Done!
  3. For Netlify: Drag-drop the HTML file at netlify.com/drop → Instant live link 🚀
  4. Share the link with all JNVians — everyone uses the same live page, anytime, anywhere! 📱
  5. Data is saved in browser localStorage — use the Export JSON button to share/backup the classmate list.
